### 5.3 Full Product Description for RRA

Excledge ERP/POS is a cloud-based, multi-tenant Enterprise Resource Planning and Point of Sale system developed in the Republic of Rwanda for the Rwandan market. The system is purpose-built to comply with the requirements of the Rwanda Revenue Authority's Electronic Billing Machine (EBM) framework, specifically the CIS/VSDC Technical Specification Version 1.0 of March 2018 and subsequent updates including the RRA ALGO EBM API Version 8.2.

The system is built on a modern, secure technology stack comprising Node.js version 20, TypeScript for type-safe server-side development, the Express web framework for RESTful API services, PostgreSQL version 16 as the primary relational database, Prisma ORM for type-safe database access, and React version 18 for the browser-based client interface. The application is deployed and accessible at https://erp.exceledgecpa.com.

The Excledge ERP/POS CIS implements the full lifecycle of VSDC-certified receipt generation in strict accordance with the RRA technical specifications. Every sale transaction generates a receipt that is transmitted to the RRA VSDC within the prescribed 1000-millisecond timeout window. The system supports all seven receipt types defined in the specification: NS (Normal Sale), NR (Normal Refund), CS (Copy Sale), CR (Copy Refund), TS (Training Sale), TR (Training Refund), and PS (Proforma Sale). All five RRA tax codes are implemented: Tax Code A (zero-rated), Tax Code B (standard-rated at 18%), Tax Code C (tax-exempt), Tax Code D (specific excise), and Tax Code E (zero-rated for exports).

The system supports a multi-tenant architecture where a single deployment serves multiple registered businesses (Organizations), each identified by their RRA-assigned nine-digit TIN and VRN. Within each Organization, multiple Branch locations are supported, each configured with its own RRA-assigned two-digit Branch ID (bhfId), EBM Device ID (ebmDeviceId), Machine Registration Code serial number (ebmSerialNo), and VSDC endpoint URL (vsdcUrl). This architecture enables a single software platform to serve multiple businesses while maintaining complete data isolation and per-branch compliance reporting.

Payment processing supports all common Rwandan payment methods: Cash, Mobile Money (including MTN MoMo and Airtel Money), Credit Card, Bank Transfer, Insurance, Debt, and Mixed payments. The system enforces stock validation at the point of sale in compliance with the specification's requirements, and maintains complete audit trails of all transactions for RRA inspection purposes.

The system operates in both live production mode (where all receipts are transmitted to and certified by the RRA VSDC) and training mode (where receipts are generated locally without VSDC transmission, for staff training purposes). The training mode is controlled at the Organization level by system administrators and produces receipts clearly marked as training receipts that cannot be used for tax purposes.

## SECTION 6: RRA DEVELOPER REGISTRATION

### 6.1 Software Developer Registration Details

The following table contains the RRA-assigned developer registration codes for Excledge ERP/POS. These codes form the foundation of the Machine Registration Code (MRC) system and are embedded in every receipt generated by the system.

| Field | Value | Notes |
|---|---|---|
| **Software Developer Identifier (BBB)** | [3 CHARACTERS — ASSIGNED BY RRA] | Three-character alphanumeric code assigned by RRA at developer registration |
| **Certificate Number (CC)** | [2 CHARACTERS — ASSIGNED BY RRA] | Two-character alphanumeric code assigned per certified software version |
| **MRC Prefix (first 5 characters)** | [BBB][CC] | Formed by concatenating the BBB and CC codes above |
| **Full MRC Format** | [BBB][CC]NNNNNN | Total 11 characters: BBB (3) + CC (2) + NNNNNN (6-digit sequential number) |

### 6.2 MRC Assignment Process

The Machine Registration Code (MRC) is a unique eleven-character identifier assigned to each POS terminal (Branch) installed at a client business. The MRC follows the format **BBBCCNNNNNN**, where:

- **BBB** — the three-character Software Developer Identifier assigned by RRA to [COMPANY LEGAL NAME]
- **CC** — the two-character Certificate Number assigned by RRA to the certified version of Excledge ERP/POS
- **NNNNNN** — a six-digit sequential number assigned incrementally to each POS terminal registered under this developer and certificate combination

The MRC appears on every receipt generated by the Excledge ERP/POS system in the CIS Information Block at the bottom of the receipt. It allows RRA to identify the software developer, the certified software version, and the specific terminal that generated any given receipt.
